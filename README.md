# 乡镇卫生院家庭病床申请巡诊耗材医保结算平台

面向乡镇卫生院的家庭病床一体化平台：**家属申请 → 家庭医生六要素评估 → 可解释排班 → 护士上门执行（体征/压疮/换药/导尿/血糖血压/用药/家属签字）→ 耗材缺货替代确认（原医嘱/替代规格/医保报销差异/可能影响→医生确认→家属签字，拒绝即补货+调整护理计划）→ 替代后伤口照片持续追踪（愈合变慢/过敏回看替代原因调材料）→ 医生调处方/复诊/转诊（远程复核）→ 护理+耗材+冷链统一账单（医保/自费一单清）→ 医保合规审查 → 全链可还原**。

技术栈：Vue 3 + Vite + Element Plus + Pinia + ECharts；Spring Boot 3.3 + Spring Security/JWT + JPA；PostgreSQL 15；Docker Compose 一键启动。

## 一、快速启动（Docker Compose，推荐）

```bash
docker compose up -d --build
```

- 前端：http://localhost:8088
- 后端 API：http://localhost:8080
- Swagger UI（OpenAPI 3 文档）：http://localhost:8080/swagger-ui.html
- PostgreSQL：localhost:5432（homebed/homebed123）

首次启动后端会自动建表并写入演示数据（9 个测试账号、4 名患者、申请/评估/计划/已完成巡诊/医嘱/风险事件/一张含合规初审结果的演示账单、一例已完成的耗材缺货替代全流程（医生确认→家属签字→伤口随访→愈合变慢风险→医生调材料）、一条今日“上门中”缺货待替代任务、两条补货任务）。

停止：`docker compose down`（保留数据加 `-v` 之外默认保留卷；清空数据用 `docker compose down -v`）。

## 四、建议的业务验证路径

1. **家属** 登录 → “建床申请”为老人提交申请（勾选护理需求）。
2. **家庭医生** 登录 → 对申请评估：病情/距离（可按坐标自动测算）/照护人/医保资格/护理项目频次/风险等级 → 批准建床或驳回。
3. **管理者** → “巡诊计划排班”选择批准单 → **智能排班**：查看三名护士在技能匹配、本周负荷、路线聚集、半径红线上的打分，以及“为什么是她、为什么不是别人”的可解释说明与基层约束权衡（系统自动生成 4 周上门任务）。
4. **护士** → “上门巡诊”对待办任务**签到上门** → 填写体征、压疮/换药/导尿/用药记录、勾选护理收费项、领用耗材（冷链药品登记交接温度）、上传现场照片、采集**家属手写签字**后提交。
   - 可验证异常：上报“家属不在家/耗材缺货/患者住院”等，任务自动挂起；管理者在“巡诊异常”中改期/改派恢复。
   - 可验证风险：血压 ≥180/110、血氧 <92%、冷链温度越界等会**自动生成风险事件**。
   - **可验证耗材缺货替代确认（本功能主线）**：在“上门巡诊”对“上门中”任务点“缺货替代”（或进入“耗材替代确认”页“发起缺货替代”）：
     1. 护士选择医嘱原品（**无菌泡沫敷料，库存 0**）与本次上门，系统列出有货候选并**自动测算规格/医保类别/报销额/自费额差异**与可能影响（水胶体敷料乙类 70% 自费更少；自粘泡沫敷料丙类全自费）。
     2. **家庭医生**登录“耗材替代确认”页查看原医嘱、替代材料规格、**医保报销差异**、可能影响后“确认替代”（可退回）。
     3. 回到护士账号：家属阅读差异后**手写签字**——选择“同意”即按替代材料执行出库（无签字不能执行）；选择“不同意”须填写本次护理计划调整，系统**自动生成加急补货任务**、登记缺货异常并改写巡诊安排。
     4. 已执行的替代单，护士可在后续上门“记录伤口随访”（照片+结论+创面面积）；选择“愈合变慢/过敏/感染”会**自动生成回挂替代单的风险事件**。
     5. **家庭医生**在“风险事件”点“回看替代原因”跳转替代单，查看原医嘱/家属签字/历次照片后“调整后续护理材料”，系统同步生成“调整护理方案”医嘱。
     6. 管理者/财务在“耗材替代确认→补货任务”对补货单“到货入库”，系统**自动为等待原品的患者安排补换药上门**并闭环缺货异常。
     7. 预置数据中患者李长顺已有一例 11 天前的完整替代：泡沫敷料缺货改用**自费**自粘泡沫敷料（家属签字、报销差 +21.20 元）、第 5 天愈合良好、第 8 天愈合变慢自动风险、医生已改凡士林油纱——可直接回看。
5. **家庭医生** 在巡诊记录中**下达医嘱**（调整处方/复诊/转诊）→ 用 `doctor2` 登录“医嘱与远程复核”完成**另一名医生远程复核**。
6. **财务** → “统一账单”按账期生成：护理服务、耗材领用、冷链药品合并为一单，自动拆分医保报销与家属自费；同来源已出账不重复计入。
7. **家属** 打开账单逐行核对（每行可回溯到巡诊记录与出库流水）→ 确认，或点“对收费有疑问”发起**收费质疑**；财务可对照“服务全链还原”答复并剔除重算。
8. **医保经办** → “医保合规审查”：查看自动初审命中规则（R1 重复收费、R2 超频次、R3 无家属签字、R4 医保资格存疑、R5 冷链温度缺失、R6 目录变化按快照结算、R7 照片证据缺失、**R8 缺货替代材料须有医生确认与家属知情签字、医保报销差异已告知**），给出复核结论后财务结算。
9. **收费/医保目录**（财务）对目录项执行“目录变更”：旧版本失效、新版本生效，历史账单不受影响（R6 会提示按出账快照还原）。
10. **管理者看板**：巡诊负荷与超时、上门半径分布与超半径患者、异常类型、风险分布、耗材消耗 Top 与缺货预警、金额概览。
11. **服务全链还原**：选择任一建床申请，查看申请→评估→排班→每次上门（签到/体征/照片/耗材/异常/医嘱/家属签字）→账单→合规→风险的完整时间线证据。

### 演示数据中预置的冲突素材

- 患者李长顺同一天两次换药（晚间敷料渗湿补换）：合规初审自动命中 **R1 重复收费/超每日限次**，可由医保经办结合家属签字与照片判定“情况属实准予报销”——体现系统是**可解释提示**而非机械拒付。
- 一支门冬胰岛素领用**未登记冷链温度** → 命中 **R5**；登记温度越界则自动生成冷链风险事件。
- 患者孙桂英住在大岭村山后（约 6km，超出 5km 半径）且有 HIGH 风险与待处理血氧风险，排班解释中给出“同片区拼单、雨雪改期、家属须在场”的安排理由。
- 患者李长顺的无菌泡沫敷料（HC007）库存为 0：已发生一例改用**丙类自费**自粘泡沫敷料的替代（家属签字知情、自费增加 21.20 元），合规初审命中 **R8 报销差异提示**；另有一条今日“上门中”任务可现场走替代两条分支。
